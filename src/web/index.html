03

ตอนนี้เกิดอะไรขึ้น?

คำอธิบายสั้น ๆ เชื่อมสถานะ Thread กับค่าที่แชร์ร่วมกัน

ตั้งค่าการทดลอง แล้วกดปุ่มเริ่มได้เลย
Shared Counter คืออะไร?

ตัวเลขกลางที่ทุก Thread ใช้อ่านและเขียน ถ้าเขียนทับกันอาจทำให้การเพิ่มค่าหาย

Lost Update ดูจากอะไร?

Thread อ่านค่าเก่าไว้ แล้วมีการเขียนแทรกก่อนที่ Thread นั้นจะเขียนค่าของตัวเอง

Lock ช่วยอย่างไร?

ล็อกชุด READ → MODIFY → WRITE ให้ทำทีละ Thread คนอื่นจึงไม่แทรกระหว่างชุดนี้
